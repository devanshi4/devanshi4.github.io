# devanshi4.github.io

Personal portfolio site for Devanshi Pandya, served by GitHub Pages at https://devanshi4.github.io.

It is a single static page: `index.html` (all CSS and JS inline) plus `photo.jpg`. The nav and hero link to `Devanshi_Pandya_Resume.pdf` at the repo root. Edit `index.html` and push to `main` to update the live site.
