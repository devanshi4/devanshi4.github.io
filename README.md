# devanshi4.github.io

Personal portfolio site for Devanshi Pandya, served by GitHub Pages at https://devanshi4.github.io.

It is a single static page: `index.html` (all CSS and JS inline) plus `photo.jpg`. `Devanshi_Pandya_Resume.pdf` is the public résumé (no phone number) linked from the nav, hero and contact section; replace it when the résumé changes. Edit `index.html` and push to `main` to update the live site.
